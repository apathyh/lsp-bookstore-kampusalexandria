# Kampus Alexandria

Tampilan (UI) website toko buku Kampus Alexandria, dibuat untuk asesmen LSP.
Ini versi statis (HTML saja) supaya bisa dibuka lewat GitHub Pages. Datanya contoh, jadi tombol hanya berpindah halaman dan belum menyimpan data.

## Halaman

**Pelanggan:** `index.html` (katalog), `aboutus.html` (tentang kami), `buku-1.html`, `keranjang.html`, `login.html`, `register.html`, `checkout.html` (ada pilihan metode pembayaran), `sukses.html`, `pesanan_saya.html`, `profil.html`

**Admin:** `admin/index.html` (dashboard), `admin/buku.html`, `admin/buku_form.html`, `admin/kategori.html`, `admin/pesanan.html`

## Cara online di GitHub Pages

1. Upload semua isi folder ini ke repository GitHub.
2. Buka **Settings > Pages**.
3. Pilih branch `main`, folder `/ (root)`, lalu **Save**.
4. Tunggu sekitar 1 menit, link muncul di halaman yang sama.

Butuh internet saat dibuka karena memakai Bootstrap dari CDN.
